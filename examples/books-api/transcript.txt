> An API should return **400 Bad Request**. The server can't process the request because the client sent invalid input, such as a malformed or unparsable parameter, so the error is on the client side and retrying the same request won't work. Some APIs use **422 Unprocessable Entity** when the syntax is valid but the values fail semantic validation, but 400 is the standard choice for a malformed parameter.
